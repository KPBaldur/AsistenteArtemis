# Road Map de Desarrollo - TodoAppRoll V2 (.NET + IA)

## Fase 1: Migración del Core a .NET (Mes 1)
- [ ] Diseño de la arquitectura de base de datos para Entity Framework Core.
- [ ] Implementación del Sistema de Autenticación con ASP.NET Core Identity y JWT.
- [ ] Migración de los endpoints de Tareas y Alarmas.
- [ ] Configuración de **SignalR** para comunicación en tiempo real.

## Fase 2: Motor de Inteligencia Artificial (Mes 2)
- [ ] Configuración del microservicio en **Python (FastAPI)**.
- [ ] Implementación de la integración con el modelo de IA vía API Key.
- [ ] Desarrollo del procesador de lenguaje natural (NLP) para creación de tareas.
- [ ] Conexión entre .NET Backend y Python AI Service.

## Fase 3: Ecosistema Móvil y Web (Mes 3)
- [ ] Refactorización del Frontend React para consumir la nueva API de .NET.
- [ ] Inicio del desarrollo de la aplicación móvil en **React Native**.
- [ ] Implementación de notificaciones push para móviles.
- [ ] Sincronización de temas y preferencias entre Web y Mobile.

## Fase 4: Especialización Microsoft y Desktop (Mes 4)
- [ ] Desarrollo de la versión de escritorio para Windows (MAUI o WebView2).
- [ ] Integración con servicios de Azure (opcional para despliegue).
- [ ] Optimización de rendimiento y seguridad del Backend.
- [ ] Pruebas de integración E2E (End-to-End).

## Fase 5: Lanzamiento y Pulido (Mes 5)
- [ ] Documentación técnica de la API (Swagger/OpenAPI).
- [ ] Despliegue en entornos de producción.
- [ ] Monitoreo de costos y uso de tokens de IA.
- [ ] Lanzamiento oficial.
